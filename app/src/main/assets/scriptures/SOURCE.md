# Scripture source

The Old Testament and New Testament text in this directory was converted from the
King James Version JSON dataset in [aruljohn/Bible-kjv](https://github.com/aruljohn/Bible-kjv).

The source repository provides all 66 books as chapter-and-verse JSON and is
distributed under the MIT License. The KJV text itself is public domain.

The Book of Mormon text was converted from the public-domain
[`bcbooks/scriptures-json`](https://github.com/bcbooks/scriptures-json)
`flat/book-of-mormon-flat.json` export.

The Doctrine and Covenants text was converted from the same repository's
`flat/doctrine-and-covenants-flat.json` export.

The Pearl of Great Price text was converted from the same repository's
`flat/pearl-of-great-price-flat.json` export.
